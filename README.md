# Conexão Verde

Projeto acadêmico de um site institucional fictício para uma ONG ambiental.

## Tecnologias
- HTML5
- CSS3
- JavaScript

## Funcionalidades
- Layout responsivo
- Seção de projetos
- Cadastro de voluntário
- Modal de adoção de árvore
- Notificações interativas

## Execução
Abra o arquivo `index.html` em um navegador ou publique o repositório em uma plataforma de hospedagem estática.
